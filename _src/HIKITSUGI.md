## このサイトについて

NEWFOR（newfor.jp）は、日本の大企業が手がけた新規事業を、公開情報だけで
1件ずつ年表に記録する「新規事業ヒストリーメディア」です。

- Vercel が main ブランチを見て自動で公開します。リポジトリのルートがそのままサイトです
- 記録は 36社 1076件。うち 931件（86%）に出来事ごとの出典リンクがついています
- 記事は15本

## 作り直し方

```
cd /home/claude
bash build.sh
```

これ1本で dist/ を作り、gh/ へ反映し、最後に `checkgen.py` が点検します。
点検で1つでもズレがあれば、そこで止まります。

サイト全体の言葉づかいの点検は `python3 _src/checksite.py`（`/tmp/audit.py` と同じもの）。

## 書くときの約束（オーナーの方針）

- 否定的な言葉を使わない（失敗・撤退・寿命）。「提供を終えた」「譲渡した」と書く
- 継続率のランキングは作らない。数えるのは、挑んだ数・張った額・組んだ相手の数
- 出典のない数字を置かない。日付が確認できない出来事は載せない
- 絵文字を使わない
- 著者名は Soichiro。記事末尾の著者プロフィールは残す（メディアらしさのため）
- サイト紹介の文章に、変わる数字（何社・何件）を入れない
- 「今日の」「今週の」など、時間を約束する言い方をページに置かない
  （古く見えた瞬間に読者が離れるため。過去に実際に指摘を受けています）
- 記事の本文の中は、上の言葉づかいの制限をゆるめてよい（オーナーの指示）
