## 2. note（note.com/newfor）

### タイトル

```
大企業の新規事業1076件を並べたら、8割がまだ生きてました
```

### 本文

```
大企業の新規事業って「どうせ続かない」イメージ、ないですか？

私もそう思ってました。派手に発表して、2〜3年で静かになって、気づいたら
名前も聞かなくなる。そういう記憶ばかりが残っています。

でも36社1076件を全部並べてみたら、答えは逆でした。
いまも続いているのが854件。8割です。

なぜ逆に感じるのか。理由ははっきりしてます。
新規事業の話って、始まるときだけニュースになるんですよね。「参入」「発表」
「開始」。その後どうなったかを、誰も追いかけません。だから記憶の中では、
たいていの新規事業が消えたことになっている。

1件ずつ調べていくと、景色がまるで変わります。

たとえば味の素。本業をやめずに、隣に利益率54%の事業を作ってました。
たとえばトヨタ。新規事業のたびに会社をつくります。2021年だけで3つ！
たとえば富士フイルム。買ってきた事業より、買わなかった事業のほうが
儲かってるんです。

どれも公開情報だけでわかることです。ただ、1社ぶんを時系列に並べた場所が
どこにもありませんでした。ないなら作るしかない。それでNEWFORを始めました。

やってることは単純です。
大企業が発表した新規事業を、開始年の古い順に並べる。
いまも続いてるのか、提供を終えたのか、他社へ渡ったのかを書く。
そして1件ずつに出典をつける。それだけ。

いちばん古い記録は1981年。いちばん新しいのが2026年。45年ぶんの年表です。

1つだけ決めていることがあります。
日付が確認できない出来事は載せません。「◯◯年ごろ」では年表になりませんから。
出典が出せないものは、どれだけ面白くても外してます。

新規事業の担当になった人が、前例として引ける場所にしたい。それが目的です。
20年この仕事をしてきて、いちばん欲しかったものを作ってます。

うまくいかなかったように見える挑戦にも、次の事業へ渡されたバトンがある。
それを一件ずつ掘り起こして残していきます。

よかったら覗いてみてください。
https://newfor.jp
```
