# 記事の材料を貯めておく場所

毎朝の自動収集が、ここに書き込みます。

## watchlist.json

見張る企業の一覧です。`state` が `記事あり` の12社は、年表に足す新しい決断を探すため。
`候補` の企業は、新しい記事を書くために動きを溜めておくためのものです。

企業を増やすときは、この JSON に1行足してください。

## queue.json

見つかった候補が入ります。1件はこの形です。

```json
{
  "id": "2026-08-06-docomo-1",
  "found": "2026-08-06",
  "company": "NTTドコモ",
  "date": "2026.08",
  "title": "○○サービスを開始",
  "url": "https://...",
  "why": "新規事業の開始にあたるため",
  "status": "new"
}
```

`status` は次の3つです。

- `new` … まだ見ていない
- `used` … 記事や年表に反映した
- `skip` … 新規事業ではなかった（理由を `why` に書き足す）

## known.json

すでに年表に入っている225件です。同じ出来事を二度拾わないための照合に使います。
記事を更新したら、`_src` の中でこのファイルも作り直してください。

## 拾う基準

新規事業として拾うのは、次のいずれかに当たるものだけです。

- 新しい会社・合弁会社の設立
- 新しい事業・サービスの開始
- 他社との資本提携、出資、買収
- 事業の譲渡、統合、提供の終了
- 新しいファンドの組成、アクセラレーターの開始

拾わないもの：決算発表そのもの、人事、受賞、既存サービスの小さな機能追加、
イベント出展、サステナビリティ報告、株主総会。

出典URLのないものは、どんなに面白くても入れません。
