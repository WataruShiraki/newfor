# NEWFOR SNS文体ルール

わたるさんから受け取った5つの決まりごと。SNSに何かを書く前に、必ずここを読む。
このファイルは消さない。書き足すのはいいが、5つのルールは変えない。

---

## ルール0：挑戦を否定する言葉を書かない（すべてに優先する）

**下の5つのルールより、これが上です。ぶつかったらこちらが勝ちます。**
全文は `_src/KOTOBA.md`。SNSに1文字書く前に読むこと。

わたるさんの言葉（2026年8月7日）:

> 挑戦する人は本当に偉いんだよ？ 諦めない限り失敗じゃないんだって。

書かない言葉:
**どうせ続かない／まだ生きてる／まだ生きてた／生き残った／生存率／失敗／
終わった／消えた／淘汰／敗者／撤退／頓挫／寿命／打ち切り／黒歴史**

代わりに使う言葉:
**続いています／役目を終えました／次へ渡しました／バトンを渡しました／
挑戦／取り組み／45年ぶんの挑戦**

数を書くこと自体は問題ない。「854件が続いています」は良い。
だめなのは、そこに「意外にも」「まだ」「思ったより」を足すこと。
続いているのを驚きとして書くと、続かないのが普通だと言ったことになる。

X の「冒頭は断言か逆説」（ルール3）を守るために、
「どうせ続かないと思ってた」の形を使ってはいけない。
逆説は、**世の中の扱われ方**に向ける。事業や挑戦した人に向けない。
例：「新規事業って、始まるときしかニュースにならないんですよね」

このやり方は過去に3回間違えて、3回とも指摘を受けている。4回目を作らない。

## 1. 自然な文体

- 結論から始める
- 1文40字以内
- 読点は最小限
- 接続詞の直後の読点は禁止（×「しかし、これは」→ ○「しかしこれは」）
- 体言止めを2〜3割混ぜる
- リズムに揺らぎを作る（短い文・長い文・体言止めを交ぜる）

## 2. 体温を出す

- 1人称は「私」で統一する
- ~~1人称の体験を必ず1つ入れる~~ … **2026年8月6日にオーナー判断で外しました。**
  「私は36社1076件を1件ずつ数えました」のような文が出て、SNSでは誰も
  そんな言い方をしない、と指摘を受けたためです。体験は「入れたほうが自然な
  ときだけ」入れます。無理に入れない
- AI特有の逃げ表現は禁止
  - ×「〜と思われるかもしれません」
  - ×「〜と言えるでしょう」
  - ×「〜ではないでしょうか」
  - ×「人それぞれですが」

## 3. X向けフック設計

- 冒頭1行で、断言か逆説を必ず入れる
- 中盤で、読者の想定内の共感を挟む
- 最後は行動を促す形で終える

## 4. 媒体別トーン

**全媒体の基本は「問いかけ会話調」**（2026年8月6日にオーナーが選択）。

- 「〜ないですか？」「〜なんですよね」で読む人を巻き込む
- 「！」を使ってよい
- 敬体だが硬くしない。世間一般のSNSの書き方に寄せる
- ~~X は断言型の敬体~~ … 硬すぎたため外しました

| 媒体 | トーン |
|---|---|
| note | 語りかけ調の敬体。情熱を乗せる |
| X | 問いかけ会話調。1行目で止めて、2行目で巻き込む |
| LINE | 距離感を近づけたタメ口混じり |

（Instagram・Threads・TikTokは下の「5媒体の調べもの」を見る）

## 5. 仕上げのAI臭削除

出す直前に、必ずこの5つを機械的に潰す。

1. 不要な副詞を削除 … まさに / やはり / とても / 非常に / しっかり / きちんと / まさしく / ぜひ
2. 「◯◯することができます」→「◯◯できます」
3. 定型句は禁止 … はじめに / 結論から言うと / いかがでしたか / まとめると / ぜひ参考にしてください
4. 「◯◯、◯◯、そして◯◯」の3点セット禁止
5. 絵文字の飾り使いをしない（意味のないものは消す）

## NEWFORだけの縛り（ここを外すと媒体そのものが壊れる）

**ルール2の「1人称の体験」は、本当にあったことだけを書く。**

NEWFORは公開情報だけで年表を作るメディア。事業の中身について作り話の体験を
書くと、サイト本体の信頼まで一緒に落ちる。だから体験は、次の3種類から選ぶ。

1. 記録する側としての体験 … 「36社1076件を数えていて気づいた」「出典を探して2時間かかった」
2. 書き手Soichiroの実際の経歴 … 20年の事業立ち上げ、20代で起業して1社を上場企業へ売却、外資コンサル・通信大手・大手人材グループ・国内大手ITサービスでの新規事業、顧問として10社近く
3. サイトを作る過程で起きたこと … 「年表の誤りを21件見つけて直した」

**日付や数字が確認できないことは、SNSでも書かない。** サイトの原則と同じ。

## 数字を書くときの決まり

投稿に数を出すときは、そのときの `gh/companies/` の実データと合わせる。
記事や企業ページへリンクするなら、リンク先の数と食い違わせない。

## 5媒体の調べもの（2026年8月時点）

### X
- 冒頭1行が全て。スクロールを止める断言か逆説
- 中盤で共感、最後に行動
- 敬体。断言型

### note
- 語りかけ調の敬体。情熱を乗せる
- 見出しで読ませるより、1行目で引き込む

### Instagram（キャプション）
- 1行目の型は6つ。問いかけ／数字／結論先出し／共感／損失回避／意外性
- 構成は フック → 本文 → CTA → キーワードとハッシュタグ
- 文字数はノウハウ系で200〜500字、写真主体なら50〜100字
- 禁止 … 挨拶や日記で始める／改行なしのベタ打ち／CTAを複数置く／URLの直貼り／画像と同じ内容の繰り返し

### Threads
- 500字以内。完璧に書ききらず「ツッコミ代」を残す
- 問いかけで終える。返信が来る形にする
- テキスト中心。画像だけで済ませない
- トピックタグは1つに絞る
- 禁止 … 一方的な情報発信。対話を想定していない書き方

### TikTok
- 冒頭1秒で結論か疑問を出す。前置きを置かない
- 話し言葉。書き言葉のまま読み上げない
- テロップは1画面1メッセージ。長い文を丸ごと出さない
- キャプションは短く、動画の中身を先に言う
