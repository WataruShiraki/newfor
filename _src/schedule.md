# NEWFOR SNS配信スケジュール

目的はサイトへの送客。数を出すことではなく、newfor.jp を開いてもらうこと。
そのため、媒体ごとに「どこにリンクを置くか」まで決めています。

---

## 週あたり25本

| 媒体 | 本数 | 時刻（日本時間） |
|---|---|---|
| X | 週12本 | 平日 7:30 と 21:00／土日 21:00 |
| Threads | 週7本 | 毎日 12:15 |
| Instagram | 週3本 | 月・水・金 20:00 |
| note | 週1本 | 火 19:00 |
| TikTok | 週2本 | 水・土 20:30 |

朝は通勤、昼は休憩、夜は帰宅後。新規事業の担当者が画面を見る時間に寄せています。

## 曜日ごとのテーマ

| 曜日 | テーマ | 送る先 |
|---|---|---|
| 月 | 1社の年表から見つけた1つのこと | その企業ページ |
| 火 | 記事の中の1節を切り出す | その記事 |
| 水 | 払った額の1件 | 投資額ランキング |
| 木 | 新規事業の言葉を1つ | 用語の記事 |
| 金 | 2社を並べて比べる | 企業ページ2つ |
| 土 | 今週足した記録のまとめ | 企業DB |
| 日 | 問いかけ。返信を集める | リンクなし |

日曜だけリンクを置きません。返信が集まる日を作ると、翌週の表示が伸びます。

## リンクの置き方（媒体ごとに違う）

- **X** … 本体にURLを置かない。ぶら下げの1本目に置く。本文にURLがあると表示が伸びにくいため
- **Threads** … 本文の最後に1つだけ。日曜はなし
- **Instagram** … キャプションのURLは飛べない。プロフィールのリンクへ誘導する
- **TikTok** … 同じくプロフィールのリンクへ
- **note** … 本文の中に2か所。前半に1つ、末尾に1つ

## 効果の見方

投稿の中のリンクは、そのままの `https://newfor.jp/...` にします。
X・Threads・note からの流入は、GA4（G-Y9N8CYZE61）が参照元を自動で見分けます。
投稿にUTMを足すと見た目が長くなるだけなので、つけません。

つけるのは、プロフィール欄のリンクだけ。ここは参照元がわかりにくいためです。

```
Instagram プロフィール  https://newfor.jp/?utm_source=instagram&utm_medium=social&utm_campaign=profile
TikTok    プロフィール  https://newfor.jp/?utm_source=tiktok&utm_medium=social&utm_campaign=profile
X         プロフィール  https://newfor.jp/?utm_source=x&utm_medium=social&utm_campaign=profile
```

## ネタは何本あるか

いま手元にある材料だけで、半年以上は回せます。

| 材料 | 出せる本数 |
|---|---|
| 36社の年表（1社から2〜3本） | 約90本 |
| 15本の記事（1本から3つの切り口） | 約45本 |
| 払った額を確認できた109件 | 109本 |
| 新規事業の言葉18個 | 18本 |
| 月ごとの新着 | 毎月1本 |

合計で260本ほど。週25本なら10週ぶんを1回転として、切り口を変えて回します。

## 進め方

1. 私が1週間ぶん（25本）の下書きをまとめて作る
2. わたるさんに全文をお見せする
3. OKが出たものだけ、その時刻に投稿する
4. 週明けに、GA4で媒体ごとの送客数を見て次の週の配分を変える

**投稿ボタンは、必ず確認を取ってから押します。** ここは変えません。

## 最初の1か月の目安

| 週 | やること |
|---|---|
| 1週目 | 初回投稿5媒体。Xは固定ポストにする |
| 2週目 | 週25本の通常運転を開始。GA4で最初の数字を見る |
| 3週目 | 伸びた型を増やし、伸びない型を差し替える |
| 4週目 | 1か月の送客数を出して、配分を組み直す |
