# NEWFOR 初回投稿 5媒体ぶん（第4案・挑戦の記録として書き直し）

## この案で何を変えたか（いちばん大事なところ）

第3案までは「どうせ続かない」「まだ生きてました」を切り口にしていました。
**これは全部やめました。** オーナーの指摘です。2026年8月7日。

> 挑戦する人は本当に偉いんだよ？ 諦めない限り失敗じゃないんだって。

NEWFOR の読者は、いま新規事業をやっている当事者です。
「どうせ続かない」は、その人たちに「あなたの仕事はたぶん無駄になる」と
言うのと同じでした。二度と書きません。詳しくは `gh/_src/KOTOBA.md`。

新しい切り口は **「挑戦の記録」** です。逆説は残しますが、向ける先を変えました。
事業や挑戦した人ではなく、**世の中の扱われ方**に向けます。

> 新規事業って、始まるときしかニュースになりませんよね。

続いている854件は書きますが、驚きとしては書きません。
「意外にも」「まだ」「思ったより」を付けたら、続かないのが普通だと
言ったことになるからです。役目を終えた事業も、同じ1件として並べます。

トーンは「問いかけ会話調」。結論から・短文・体言止め・AI臭削除の4つを守る。

数字は 2026年8月7日時点の実データ。
36社1076件／継続中854件／1981〜2026年／出典1117件／
発表日まで確定500件／Soichiroの一言206件。

送り先は `/news/`。1076件が日付順に並んでいる画面のほうが、
トップより「本当に全部ある」ことが1秒で伝わります。

## 2. note（note.com/newfor）

### タイトル

```
新規事業の「その後」を誰も書かないので、1076件ぶん書きました
```

### 本文

```
新規事業って、始まるときしかニュースになりませんよね。

「参入」「発表」「開始」。派手な見出しが並ぶのは最初だけです。その事業がその後どこまで届いたのかを書いた記事は、探してもほとんど出てきません。

だから作りました。36社1076件。1981年から2026年までの45年ぶんです。

並べてみて、まず思ったこと。挑戦の量がすごい。

トヨタは新規事業のたびに会社をつくります。2021年だけで3つ！
味の素は本業を持ったまま、隣に利益率54%の事業を育てていました。
富士フイルムは買ってきた事業より、買わなかった領域のほうが伸びています。

どれも公開情報だけでわかることです。ただ、1社ぶんを時系列に並べた場所がどこにもありませんでした。ないなら作るしかない。それでNEWFORを始めました。

やっていることは単純です。
大企業が発表した新規事業を、始まった年の古い順に並べる。
いまも動いているのか、役目を終えたのか、他社へ渡ったのかを書く。
そして1件ずつに出典をつける。それだけです。

いま動いているのが854件。1981年に始まって、今日まで続いているものもあります。

ここで1つ決めていることがあります。
役目を終えた事業を、続いている事業より下に置かない。同じ1件として、同じ書き方で残します。

新規事業って、始めた時点でもう仕事をしてるんですよね。稟議を通した人がいて、反対を押し返した人がいて、名前の出ない担当者がいる。形が変わったからといって、それが無かったことにはなりません。次の事業に人が移って、そこで技術が生きている。そういう筋を、この年表の中で何度も見ました。

そして今日、1076件のぜんぶに専用のページを用意しました。

1件開くと、何があったかの要約、一次情報へのリンク、その会社が前後に何をしていたか、同じころ他社は何をしていたかが並びます。直近のものには私のコメントも添えました。「この順番、逆じゃないところに意図がある」みたいな、並べて初めて見えることを書いてます。

もう1つ決めていること。
日付が確認できない出来事は載せません。「◯◯年ごろ」では年表になりませんから。出典が出せないものは、どれだけ面白くても外しています。発表日も、出典に書いてある日だけ。推測で埋めません。

新規事業の担当になった人が、前例として引ける場所にしたい。それが目的です。20年この仕事をしてきて、いちばん欲しかったものを作ってます。

よかったら覗いてみてください。
https://newfor.jp/news/
```
