# いちばん上の決まり ── 挑戦を否定する言葉を書かない

**このファイルは、NEWFOR のすべての文章に効く最上位のルールです。**
サイト本体・記事・SNS・広告・Soichiroの一言・投票、どれにも例外なく効きます。
他のどのルールとぶつかっても、こちらが勝ちます。

新しく担当するときは、何を書き始めるより先にここを読んでください。

---

## なぜこの決まりがあるのか

オーナー（わたるさん）の言葉をそのまま残します。2026年8月7日。

> 挑戦する人は本当に偉いんだよ？
> 諦めない限り失敗じゃないんだって。

NEWFOR が記録しているのは、大企業の中で新しいことを始めた人たちの仕事です。
その一件ずつの後ろに、稟議を通した人がいて、反対を押し返した人がいて、
名前の出ない担当者がいます。読者もまた、いま同じことをやっている人たちです。

「どうせ続かない」「まだ生きてた」と書くことは、その人たちに向かって
「あなたのやったことは、たぶん無駄になる」と言うのと同じです。
NEWFOR は、それを絶対にやりません。挑戦したこと自体を価値として扱います。

過去に3回、同じ間違いをしてオーナーから指摘を受けています。
1回目は投票企画の選択肢、2回目は投票企画の作り直し、3回目はSNSの初回投稿です。
4回目を起こさないために、このファイルがあります。

## 書かない言葉

見つけたら、そのまま出さずに必ず書き換えます。

| 書かない | なぜ |
|---|---|
| どうせ続かない | 挑戦そのものを最初から否定している |
| まだ生きてる／まだ生きてた | 死んでいて当然、という前提が失礼 |
| 生き残った／生存率 | 残らなかったものを敗者にしている |
| 失敗／しくじり／爆死 | 諦めない限り失敗ではない |
| 終わった／終わってる | 次に渡ったものを、無かったことにしている |
| 消えた／消滅した | 同じ |
| 淘汰／敗者／勝ち組・負け組 | 順位づけをする言葉 |
| 撤退／頓挫／挫折 | 手を引いたことを負けとして描く |
| 寿命／short-lived | 事業を、勝手に死ぬものとして扱っている |
| 打ち切り／お蔵入り | 同じ |
| 黒歴史／爆死案件 | 論外 |

「8割が続いていました」のような**数の書き方そのものは問題ありません。**
問題になるのは、そこに「意外にも」「まだ」「思ったより」を足したときです。
続いていることを驚きとして書くと、続かないのが普通だと言ったことになります。

## 代わりに使う言葉

| 起きたこと | こう書く |
|---|---|
| いまも続いている | 続いています／いまも動いています／今日まで続いています |
| 提供を終えた | 役目を終えました／提供を終えました |
| 他社へ渡した | 次へ渡しました／バトンを渡しました／他社が引き継ぎました |
| 会社をたたんだ | 事業を統合しました／別の形にまとめました |
| 事業そのもの | 挑戦／取り組み／打った手／張った賭け |
| 記録全体 | 挑戦の記録／45年ぶんの挑戦 |

## 姿勢の決まり（言い換えだけでは足りない部分）

1. **続いたものと、次へ渡したものを、同じ重さで書く。**
   続いた側を勝ち、渡した側を負け、という書き分けをしない。
2. **継続率のランキングを作らない。**
   数えてよいのは、挑んだ数・張った額・組んだ相手の数。
3. **意外性で引っぱらない。**
   「実は」「意外にも」「思ったより」を、事業の続き方に対して使わない。
4. **読者は挑戦の当事者だと思って書く。**
   外から眺めて論評する立場に立たない。
5. **会社を持ち上げない。けなさない。** 事実を並べて、読む人に渡す。

## 出す前の確認

SNS・記事・ページ、どれを出すときも最後にこれをやります。

```
python3 _src/checksite.py     # 生成物ぜんぶの言葉づかいを見る
```

手で書いた文（SNSの下書きなど）は、上の「書かない言葉」の表を
そのまま目で当ててください。1語でも入っていたら、出しません。
